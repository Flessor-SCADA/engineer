# Segurança

Encontrou uma falha de segurança nesta skill ou no produto? **Não abra issue pública.**

Escreva para **security@flessak.com.br** com a versão do produto, o que você fez e o que aconteceu.

Antes de usar, leia a seção **Segurança** do [README](README.md): ela descreve o que a skill pode fazer e quais dados passam pelo agente.
